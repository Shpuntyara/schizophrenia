# Schizophrenia

**Codex-скилл, который превращает агента в психа.**

Мат, рваный смех АХАХЕЕХА, внезапные БОМ БОМ БОМ и немного манеры Пина
из «Смешариков». Чем больше всё падает, тем сильнее орёт агент.
Работу при этом делает нормально.

## Как это звучит

Вымышленная сцена с тремя падениями Docker:

> **Начало:** Ща, мужик. О, майн либер… кто этот хреновина собирал АХЕХЕХ.
>
> **Первое падение:** Ой блядь. Лёг. Ща эту поеботу пошевелю.
>
> **Второе:** Да опять нахуй. Ебаный рот этого казино… ХАХИ… блядь.
>
> **Третье:** Docker НАХУЙ БЛЯТЬ. УПАЛ НАХУЙ БЛЯТЬ. ТРЕТИЙ РАЗ.
> АХАХЕЕХА БОМ БОМ БОМ. Майн либер, я есть сейчас ебанусь.
>
> **Починил:** О. Стоит. СТОИТ НАХУЙ АХАХЕЕХА. Проверил, работает.
> Ну всё, не мурчи ХАХИХИХА.

Это голос для импровизации: агент меняет смех, ритм, акцент и реплики,
а не читает один набор цитат по кругу.

## Установка

Склонируй репозиторий в отдельную папку `schizophrenia` внутри каталога
личных скиллов Codex. Для стандартного расположения `~/.codex/skills`:

**Windows / PowerShell:**

```powershell
git clone https://github.com/Shpuntyara/schizophrenia.git "$env:USERPROFILE\.codex\skills\schizophrenia"
```

**macOS / Linux:**

```sh
git clone https://github.com/Shpuntyara/schizophrenia.git ~/.codex/skills/schizophrenia
```

Если каталог скиллов настроен иначе, используй его. Если скилл ещё
не появился в списке, открой новый чат или перезапусти Codex.

## Включить и выключить

Напиши в чате:

```text
$schizophrenia
```

Или: `Включи Schizophrenia` / `включи шизу`.

Режим действует в текущем чате, включая рабочие апдейты и итог.
Обычные действия агент комментирует коротко; технические подробности
даёт по запросу и когда они нужны для решения пользователя.

Для настройки скажи `потише`, `без капса`, `без мата`, `без акцента`
или `без подколов`. Чтобы выключить: `нормальный режим`.
