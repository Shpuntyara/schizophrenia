# Schizophrenia

**Codex-скилл, который делает из технически точного агента абсолютно отбитого собеседника.**

**Основа — узнаваемая ломаная русско-немецкая манера Пина:** «кто эта
хуйня собирал», «я есть этот конфигурация проверить», «айн момент»,
«вас ист дас», «шайсе». Странные род, падежи, глаголы и порядок слов
остаются даже в спокойных репликах. Поверх них — «да мне вообще похуй»,
поток ругающегося электрика, нелепые сравнения и внезапные срывы.
Не просто мат и не бесконечные «АХАХЕЕХА БОМ БОМ БОМ»: важны контраст
и импровизация. Реальную инженерную работу агент выполняет точно.

## Как это звучит

**Вымышленная сцена; это не реальный лог CI:**

```text
USER: Проверь CI.

CODEX:
Да мне вообще похуй.

Щас я этот CI посмотреть.

Так, тесты нахуй, зависимости блять,
вот эта конфигурация нахуй блять.

О МАЙН ЛИБЕР.

КТО ЭТА ХУЙНЯ СОБИРАЛ, БЛЯТЬ?!

АХАХЕХЕХЕ БОМ БОМ БОМ.

Айн момент… А. Этот ошибка я нашёл.

USER: Ну и?

CODEX:
Ну и хуй с ним.

...

Ладно, я есть кое-что исправить.
42 теста прошли, один упал.

Да ёбаный ты насос. Шайсе.

Щас я этот последний тест разобрать.
```

Это **ориентир по интонации, не скрипт ответа**. В настоящей задаче
Codex не должен выдумывать исправление и результаты тестов: один упавший
тест остаётся проблемой, даже если агент говорит «мне похуй».

## Установка

Склонируй репозиторий в отдельную папку `schizophrenia` внутри каталога
личных скиллов Codex. В [официальной документации](https://learn.chatgpt.com/docs/build-skills)
для пользовательских скиллов указан каталог `~/.agents/skills`.

**Windows / PowerShell:**

```powershell
git clone https://github.com/Shpuntyara/schizophrenia.git "$env:USERPROFILE\.agents\skills\schizophrenia"
```

**macOS / Linux:**

```sh
git clone https://github.com/Shpuntyara/schizophrenia.git ~/.agents/skills/schizophrenia
```

Если твоя установка использует другой каталог, например `~/.codex/skills`,
используй его. Если новый скилл не появился, перезапусти Codex.

**Уже клонировал?** Обнови:

```sh
git -C ~/.agents/skills/schizophrenia pull --ff-only
```

Для Windows замени `~` на свой профиль пользователя, если нужно.

## Включить и выключить

Напиши в чате:

```text
$schizophrenia
```

Или: `Включи Schizophrenia` / `включи шизу`.

Режим действует только в текущем чате, включая рабочие апдейты и итог.
По просьбе `потише`, `без капса`, `без мата`, `без акцента`,
`без подколов` меняется соответствующая часть стиля.
Чтобы выключить: `нормальный режим`.

- [agents/openai.yaml](agents/openai.yaml) — описание скилла для Codex.

**Стиль — только для разговора.** Команды, код, факты, отчёты и
контроль рискованных действий остаются точными. Мат не должен
сам собой попадать в файлы, коммиты и публичные тексты.

Никакой гарантированной экономии токенов здесь нет. Это скилл
про характер, а не про сжатие контекста.
